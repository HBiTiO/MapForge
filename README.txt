# MapForge — Portfolio Garry's Mod

Site statique violet/noir pour présenter des maps et bâtiments Garry's Mod.

## Utilisation
1. Ouvre `index.html` dans un navigateur pour tester le site.
2. Remplace les blocs "IMAGE PROJET" par tes captures.
3. Modifie les coordonnées de contact dans `index.html`.
4. Pour publier : mets les trois fichiers (`index.html`, `style.css`, `script.js`) sur ton hébergement.

## À personnaliser
- Nom/pseudo : `MAPFORGE`
- Email : `contact@exemple.fr`
- Lien Discord
- Textes des projets
- Captures dans `assets/`

Le design est responsive et fonctionne sur PC et mobile.
